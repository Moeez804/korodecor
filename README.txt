KoroDecor — V2 Enhanced
========================
This version intentionally keeps the original KoroDecor V2 structure/design direction,
while improving the details rather than replacing it with a new template.

Enhancements:
- Clean supplied KoroDecor logo treatment (no forced circular crop)
- Animated premium announcement marquee
- More refined sticky/glass header
- Hero micro-details and subtle depth/hover treatment
- Product wishlist controls and more polished product cards
- Improved spacing, shadows and visual hierarchy
- Responsive mobile adjustments

Demo/reference product photography is temporary and should be replaced with the client's
own photography before production.

Mobile header: logo is mathematically centered against the full viewport, independent of the left/right icon widths.
